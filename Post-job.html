Post a Job
Create your own job instructions and choose the proof workers need to submit.
📋 Job Details
Write the job exactly the way you want the worker to understand it.
The worker will see your instructions on the Perform Task page.
Optional. When provided, workers can tap Open Link to visit it.
Optional. This can be a comment, code, message, username, text or anything else.
📸 Proof Requirements
Choose what the worker must submit to prove that the job was completed.
💡 Make the proof match your instructions.
For example, if you ask for a screenshot, enable Photo. If you ask for an ID, enable Reference ID. You can select more than one.
📷
Photo / Screenshot
Worker uploads a photo or screenshot as proof.
👤
Username
Worker provides a username or account name.
📝
Text / Answer
Worker writes an answer, explanation or other information.
🔗
URL / Link
Worker submits a link as part of the proof.
🆔
Reference ID
Worker provides an order, registration or confirmation ID.
▶️
Watch Timer
Use when your job requires workers to watch content for a set time.
Example: enter 60 for a one-minute watch requirement.

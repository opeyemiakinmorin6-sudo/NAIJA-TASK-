Frequently Asked Questions

Some common questions about the TASK NAIJA platform.

What is TASK NAIJA?

TASK NAIJA is a platform concept for publishing tasks, receiving member submissions and managing eligible rewards.

How do I complete a task?

Open an available task, read all requirements carefully, complete the instructions and submit the requested proof.

How are submissions reviewed?

Submitted proof can be reviewed by an administrator before a task is marked as approved or rejected.

Are withdrawals available now?

The current website is the front-end stage. A secure backend and properly configured payment/withdrawal system must be connected before real withdrawals are activated.
